### JavaScript
- Lesson 1 - Introduction to JavaScript
- Lesson 2 - Variables (Learned JavaScript variables including var, let and const, undefined, mathematical assignment operators, string concatenation, template literals   using backticks and typeof keyword.)
- Lesson 3 (Conditional Statements .Learned conditionals including if, if...else, else if, comparison operators, logical operators (&&, ||, !), ternary operator and switch statements.)
 Lesson 4 & 5 - Functions and Scope(Description:
Learned JavaScript functions including function declarations, function expressions, arrow functions, parameters, default parameters and return statements. Also learned scope including global scope, block scope, local variables, global variables, namespace and scope pollution.)
